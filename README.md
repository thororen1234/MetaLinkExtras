# MetaLinkExtras

A Windows system-tray app that combines Meta Quest / Horizon Link utilities into one settings panel.

## Features

| Toggle | Description |
|---|---|
| **Send Meta Link to Tray** | Automatically minimises Meta Horizon Link to the system tray on startup (port of [MetaTrayApp](https://github.com/NyLan-1/MetaTrayApp)) |
| **Kill Oculus Dash** | Replaces `OculusDash.exe` to kill the dash and auto-launch SteamVR when Link starts (TypeScript port of [OculusKiller](https://github.com/BnuuySolutions/OculusKiller)) |
| **Kill SteamVR on Exit** | Automatically exit SteamVR when Oculus Link is closed |
| **Launch with Windows** | Registers MetaLinkExtras in the Windows startup items |
| **Run in System Tray** | Keep MetaLinkExtras running quietly in your taskbar corner |
